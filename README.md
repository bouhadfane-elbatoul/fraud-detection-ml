# Fraud Detection System using Machine Learning

## Description
This project aims to detect fraudulent financial transactions using Machine Learning techniques and the PaySim dataset.

## Features
- Fraud prediction
- Exploratory Data Analysis (EDA)
- Benchmark of ML models
- XGBoost classifier
- SMOTE & Undersampling
- Interactive Streamlit dashboard

## Technologies Used
- Python
- Pandas
- Scikit-learn
- XGBoost
- Streamlit
- Plotly

## Models
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

## Best Model
XGBoost + Imbalanced Dataset
